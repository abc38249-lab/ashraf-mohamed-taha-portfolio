# Healthcare Facility — Patient Affairs & CBAHI Quality Analytics | 2015

**Role:** Quality Specialist | Data Analyst  
**Portfolio:** MAOS Healthcare Analytics

Power BI architecture for an anonymized 2015 Patient Affairs / Quality analytics case study.

## Report architecture
1. Executive Overview
2. Patient Flow
3. Quality & CBAHI
4. Data Quality

## Model scope
Admissions, Discharges, Transfers, Daily Census, Length of Stay, KPI monitoring, data validation and quality/accreditation support.

## Data integrity rule
The prototype/demo values used during model development are synthetic placeholders. They are not presented as verified historical 2015 figures. Production publication requires mapping and reconciling the original verified 2015 source data.

## Privacy
The public project intentionally omits the healthcare facility name and identifying information. Direct patient identifiers must never be included in the public portfolio dataset.

## Package
The complete downloadable build package contains the Power BI-ready Excel source model, DAX measures, Power Query transformation plan, MAOS theme and report-page specification.

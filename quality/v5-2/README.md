# MAOS — Quality Specialist & Data Analyst — V5.2

Public portfolio module for **Ashraf Mohamed Taha**.

## Featured case study
**Healthcare Facility — Patient Affairs & CBAHI Quality Analytics | 2015**

This module presents a modern, anonymized reconstruction of a real 2015 Patient Affairs analytics workflow. It demonstrates healthcare data analysis, operational KPI monitoring, data validation, reporting, and quality/accreditation support.

## Public-data policy
The healthcare facility name and identifying information are intentionally omitted. Dashboard values in the public prototype are presentation-safe/anonymized unless explicitly verified against the original historical source dataset. No identifiable patient data is published.
